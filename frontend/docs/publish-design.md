# 内容发布页面设计文档 MobilePublish

## 1. 概述

**页面名称**: MobilePublish
**路径**: `/mobile/publish`
**功能**: 支持发布「文章」和「商品」两类内容
**技术栈**: React 18 + React Router 6 + antd-mobile 5.x

---

## 2. 交互与布局

### 2.1 页面结构

```
┌─────────────────────────────┐
│  Header (固定顶部)            │  ← 返回按钮 + "发布内容" 标题
├─────────────────────────────┤
│  Segmented 切换              │  ← 「发布文章」/「发布商品」
├─────────────────────────────┤
│  表单区域 (可滚动)            │
│  ├─ 文章表单                 │
│  │   ├─ 标题 (2-40字)        │
│  │   ├─ 正文 (textarea)      │
│  │   ├─ 分类下拉             │
│  │   ├─ 位置输入             │
│  │   ├─ 封面图 (可选,最多1张) │
│  │   └─ 配图 (可选,最多9张)   │
│  │                         │
│  └─ 商品表单                 │
│      ├─ 商品标题 (5-60字)    │
│      ├─ 描述 (最多500字)     │
│      ├─ 多图上传 (1-9张,1:1) │
│      ├─ 价格 / 原价          │
│      ├─ 新旧程度 (单选)      │
│      ├─ 交易方式 (多选)      │
│      └─ 联系电话 (可选)       │
├─────────────────────────────┤
│  底部固定发布按钮 (sticky)     │  ← 粘连底部
└─────────────────────────────┘
```

### 2.2 Segmented 类型切换

- 默认选中「发布文章」
- 切换时保留两种类型的内容状态（useState 分别管理）
- 切换动画：淡入淡出

## 3. 表单字段详细说明

### 3.1 文章表单

| 字段 | 组件 | 限制 | 说明 |
|------|------|------|------|
| 标题 | Input | 2-40字 | 实时计数 |
| 正文 | Textarea | 最大10000字 | 实时计数，行数8 |
| 分类 | Select/Picker | — | 预设选项：读书/生活/科技/旅行/其他 |
| 位置 | Input | — | 可选，文字描述地点 |
| 封面图 | ImageUploader | 最多1张, ≤10MB | 格式: jpg/png/webp，比例自由 |
| 配图 | ImageUploader | 最多9张, ≤10MB/张 | 格式: jpg/png/webp |

### 3.2 商品表单

| 字段 | 组件 | 限制 | 说明 |
|------|------|------|------|
| 商品标题 | Input | 5-60字 | 实时计数 |
| 商品描述 | Textarea | 最多500字 | 可选 |
| 多图上传 | ImageUploader | 1-9张, 1:1比例, ≤10MB/张 | 必填，1:1裁剪提示 |
| 价格 | Input (number) | 必填，正数 | 单位元 |
| 原价 | Input (number) | 可选，正数 | 对比折扣 |
| 新旧程度 | RadioGroup | 单选 | 全新/几乎全新/有使用痕迹/老旧 |
| 交易方式 | Checkbox Group | 多选 | 同城面交/快递邮寄/自提 |
| 联系电话 | Input | 可选 | 手机或电话 |

## 4. 图片上传组件行为

### 4.1 上传流程
1. 点击上传区域打开系统相册/相机
2. 选择图片后显示缩略图（已选列表）
3. 上传中显示 `Loading` 动画遮罩
4. 上传完成后显示缩略图

### 4.2 缩略图列表
- 网格布局（每行3-4张）
- 每张图右上角有删除按钮 (×)
- 支持拖拽排序（原生 HTML5 drag & drop）
- 删除后重新渲染列表

### 4.3 限制
- 单张文件 ≤ 10MB
- 格式: jpg / png / webp
- 商品多图：建议 1:1 比例，超出部分裁切显示

### 4.4 错误处理
- 文件过大 → Toast 提示"单张图片不能超过10MB"
- 格式错误 → Toast 提示"仅支持 jpg/png/webp 格式"
- 超出数量 → Toast 提示"最多上传X张图片"

## 5. 底部发布按钮

### 5.1 样式
- 固定在底部 (position: sticky bottom)
- 高度: 56px
- 背景: 主色调 (#1677ff 或项目主题色)
- 文字: 白色，"发布" / "立即发布"

### 5.2 行为
- 点击后 disable 防止重复提交
- 显示 Button loading 状态
- 校验失败 Toast 提示第一条错误
- 成功后 Toast 提示并 navigate 回 `/mobile/square`

---

## 6. 校验规则

### 文章
- 标题: 必填，2-40字
- 正文: 必填，不超过10000字
- 封面图: 可选
- 配图: 可选，总数≤9张

### 商品
- 标题: 必填，5-60字
- 多图: 必填，1-9张
- 价格: 必填，正数
- 新旧程度: 必选
- 交易方式: 必选至少一种

---

## 7. 错误处理

### 7.1 网络错误
- Toast 浮层提示"网络错误，请稍后重试"
- 保留表单内容（不清空）
- 按钮恢复可点击状态

### 7.2 业务错误
- API 返回错误 message → Toast 显示
- HTTP 非 2xx → Toast 显示"发布失败"
