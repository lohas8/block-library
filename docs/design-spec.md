# Block Library 设计规范

> 社区共享图书管理系统 · 设计基准文档  
> 版本：v1.0 | 更新：2026-05-29

---

## 1. 品牌定义

### 1.1 品牌定位
**Block Library** — 社区共享图书管理系统。核心理念是"信任、协作、共享"，强调社区居民通过 AI + 区块链技术实现自治。

### 1.2 调性关键词
| 关键词 | 含义 | 应用场景 |
|--------|------|----------|
| **温暖** | 邻里之间的信任感，非冰冷的工具感 | 色调偏暖、圆角卡片、社区氛围插图 |
| **可信** | 信息透明、积分可信、流程可追溯 | 状态明确、色块干净、不混淆 |
| **轻量** | 操作路径短、信息密度适中 | 页面留白、层级清晰、避免信息过载 |
| **现代** | 简洁利落、不老气 | 深色强调色、扁平化、少装饰 |

### 1.3 竞品参考
- **微信读书**：卡片式书籍展示、阅读进度
- **多抓鱼**：简约图书卡片、状态标签
- **蚂蚁森林**：积分可视化、成就激励

## 3. 字体系统

### 3.1 字号梯度
| 层级 | 字号 | 字重 | 使用场景 |
|------|------|------|----------|
| 大标题 | 20px | 600 | 页面主标题（"议事广场"） |
| 标题 | 16px | 600 | 卡片标题、列表项标题 |
| 正文 | 14px | 400 | 正文内容、描述文字 |
| 辅助 | 12px | 400 | 标签、时间戳、辅助说明 |
| 最小 | 10px | 400 | 极小提示、版权信息 |

### 3.2 行高规则
- 标题：行高 1.3（紧凑）
- 正文：行高 1.6（可读）
- 辅助文字：行高 1.4

## 4. 间距系统

### 4.1 基础单位
**8px 网格系统**。所有间距为 8px 的倍数。

| Token | 数值 | 使用场景 |
|-------|------|----------|
| `space-xs` | 4px | 标签内 padding、紧凑元素间 |
| `space-sm` | 8px | 列表项内元素间距 |
| `space-md` | 16px | 区块内间距、组件内 padding |
| `space-lg` | 24px | 页面区块间距 |
| `space-xl` | 32px | 大区块间距（顶部/底部留白） |

### 4.2 卡片间距
- 卡片 padding：`16px`
- 卡片间距（列表）：`8px`
- 卡片圆角：`12px`
- 卡片阴影：`0 2px 8px rgba(0,0,0,0.06)`

## 5. 组件规范

### 5.1 按钮
| 类型 | 样式 | 使用场景 |
|------|------|----------|
| 主按钮 | 实心 `#1A1A1A`，白色文字，圆角 8px | 主要操作（借书/提交/发布） |
| 次按钮 | 描边 `#1A1A1A`，透明背景，圆角 8px | 次要操作（取消/返回） |
| 危险按钮 | 实心 `#F5222D`，白色文字，圆角 8px | 删除/取消借阅 |
| 文字按钮 | 无边框，文字色 `#1A1A1A` | 辅助操作（查看更多） |
| 禁用 | 背景 `#F5F5F5`，文字 `#999999` | 不可点击状态 |

### 5.2 卡片
| 类型 | 样式 |
|------|------|
| 图书卡片 | 封面图（封面比 3:4）+ 标题 + 作者 + 状态标签 + 操作按钮 |
| 议题卡片 | 标题 + 描述（2行截断）+ 标签组 + 参与人数 |
| 投票卡片 | 标题 + 进度条（同意绿色/反对红色）+ 参与人数 + 截止时间 |

### 5.3 导航
| 组件 | 说明 |
|------|------|
| 侧边栏 | 左侧固定，宽度 200px，白色背景，含 logo + 菜单项 |
| 底部导航 | 移动端 5 项，图标+文字，AI 项圆形突出（top: -4px） |
| Tab 标签 | 横向滚动标签组，选中态下划线 `#1A1A1A` |

### 5.4 表单
| 元素 | 规范 |
|------|------|
| 输入框 | 高度 40px，圆角 8px，边框 `#F0F0F0`，聚焦边框 `#1A1A1A` |
| 选择器 | 同输入框样式，下拉箭头右侧 |
| 星级评分 | 5 星，点击/展示两种状态，金色 `#FAAD14` |

## 6. 页面评分卡（设计评审用）

每次交付前，Designer 必须完成以下评审：

### 6.1 七维度评分（百分制）

| # | 维度 | 权重 | 合格线 | 评审标准 |
|---|------|------|--------|----------|
| 1 | 布局结构 | 20% | ≥16/20 | 8px 网格对齐、留白均匀、信息密度合理 |
| 2 | 色彩运用 | 20% | ≥16/20 | 严格使用品牌色板，对比度 ≥4.5:1 |
| 3 | 字体层级 | 15% | ≥12/15 | 标题/正文/辅助三级可辨，字号梯度正确 |
| 4 | 组件规范 | 15% | ≥12/15 | 按钮/卡片/表单与本规范一致 |
| 5 | 交互友好 | 15% | ≥12/15 | 状态齐全（默认/悬停/按下/禁用/空态） |
| 6 | 品牌契合 | 10% | ≥8/10 | 整体风格符合"温暖·可信·轻量·现代" |
| 7 | 技术还原 | 5% | ≥4/5 | 与设计稿误差 ≤5% |

### 6.2 综合得分

| 得分 | 结论 | 操作 |
|------|------|------|
| **≥ 80** | ✅ 合格 | 可以交付 |
| **60–79** | ⚠️ 需修改 | 列出问题清单，修改后复审 |
| **< 60** | ❌ 不合格 | 打回重做，Designer 重新输出 |

### 6.3 评审 Checklist（必须全部通过）

- [ ] 所有文本与设计标注一致
- [ ] 间距符合 8px 网格
- [ ] 组件状态齐全（5 种状态）
- [ ] 色彩严格使用品牌色板，无自由发挥
- [ ] 图标风格统一（线性一致）
- [ ] 移动端 / PC 端均已适配
- [ ] 空数据、网络错误、加载中状态已覆盖

## 7. 移动端特殊规范

### 7.1 尺寸基准
- 设计稿基准：`375 × 812`（iPhone 14）
- 安全区域：顶部 44px，底部 34px

### 7.2 触控目标
- 最小点击区域：`44 × 44px`
- 按钮高度建议：`40–48px`
- 列表项高度：`≥ 48px`

### 7.3 底部导航规范
```
位置：fixed，底部
高度：56px + safe-area-bottom
背景：白色 + 上边框 #F0F0F0
AI 突出项：圆形 32px，top: -4px，背景 #1A1A1A
```

### 7.4 物业评价卡片
```
3 列网格：整体服务 | 维修响应 | 环境绿化
每列：星级 + 分数 + 标签文字
"去评价"按钮 → 跳转评价页
```

## 8. 特殊场景样式

### 8.1 积分激励色
```
获得积分：绿色 + 图标 +
消费积分：橙色 + 图标 -
```

### 8.2 借阅状态
| 状态 | 标签色 | 操作按钮 |
|------|--------|----------|
| 在馆 | `#E8F5E9` 绿 | 立即借阅 |
| 已借出 | `#FFF3E0` 橙 | 查看进度 |
| 预约中 | `#E3F2FD` 蓝 | 取消预约 |
| 逾期 | `#FFEBEE` 红 | 请尽快还书 |

### 8.3 议事广场热度色
```
hot_score = (follow × 0.6 + comment × 0.4) × e^(-0.15 × hours)
热议标签：黑底白字
投票中：绿底绿字
已结束：灰底灰字
```
