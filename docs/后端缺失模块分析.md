## 二、缺失模块详细说明

### 1. 工具共享模块 (tool)

**前端需求** (`frontend/src/pages/Tools.js`):
```javascript
toolApi.list(params)           // 工具列表
toolApi.detail(id)              // 工具详情
toolApi.create(data)            // 创建工具
toolApi.update(id, data)        // 更新工具
toolApi.delete(id)              // 删除工具
toolApi.categories()            // 分类列表
toolApi.rent(data)              // 租用工具
toolApi.return(id)              // 归还工具
toolApi.statistics()            // 统计
```

**数据模型**:
- tool: { name, category, image, description, depositPoints, rentPointsPerDay, status, owner, ownerName, borrower, dueDate }

---

### 2. 小区管理模块 (community)

**前端需求** (`frontend/src/pages/CommunityManage.js`):
```javascript
communityApi.list(params)       // 小区列表
communityApi.detail(id)         // 小区详情
communityApi.create(data)       // 创建小区
communityApi.update(id, data)   // 更新小区
communityApi.delete(id)         // 删除小区
```

**数据模型**:
- community: { name, address, adminName, status, createdAt }

---

### 3. 规则管理模块 (rule)

**前端需求** (`frontend/src/pages/RuleManage.js`):
```javascript
ruleApi.list(params)            // 规则列表
ruleApi.detail(id)              // 规则详情
ruleApi.create(data)            // 创建规则
ruleApi.update(id, data)       // 更新规则
ruleApi.delete(id)              // 删除规则
ruleApi.apply(ruleId, data)     // 申请规则
ruleApi.approve(id)             // 批准申请
ruleApi.reject(id)              // 拒绝申请
ruleApi.listApprovals(params)   // 申请列表
```

**数据模型**:
- rule: { name, content, points, type (reward/punishment), communityId, status }
- ruleApproval: { ruleId, userId, status, createTime }

---

### 4. 用户 API 缺失的接口

**前端需求**:
```javascript
userApi.getInvites(userId)           // 获取我邀请的用户
userApi.getInvitedBy(userId)         // 获取邀请我的人
userApi.getAppliedRules(userId)      // 获取我申请的规则
```

---

## 三、建议实现顺序

1. **tool** - 工具共享（业务逻辑简单，可快速完成）
2. **community** - 小区管理（基础数据模块）
3. **rule** - 规则管理（涉及申请审批流程，较复杂）
4. **user 扩展** - 补充缺失的3个接口
